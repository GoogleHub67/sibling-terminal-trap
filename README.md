# Sibling Terminal Trap Suite 🏴‍☠️

A lightweight suite of cross-platform terminal simulation tools for shell testing and harmless pranks. Features custom matrix streams, text buffers, audio alerts, and terminal intercept traps for Linux (.sh), Windows Batch (.bat), and PowerShell (.ps1).

## 📋 Audio Prerequisites (Linux Only)
Windows scripts handle audio natively. For Linux terminal sounds to work correctly, ensure `sox` is installed:

```bash
# Debian / Ubuntu / Mint
sudo apt update && sudo apt install sox -y
```

## 🛡️ Quick Setup

### Linux Intercept Trap
Append the contents of `trap.sh` as an alias in your local `~/.bashrc` or `~/.zshrc` file:
```bash
source ~/.bashrc
```

### Windows Deployment
The `.bat` file executes instantly via a standard double-click, completely bypassing default Windows script execution blocks.
